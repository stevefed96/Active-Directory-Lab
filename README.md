# Active-Directory-Lab

Project Status: In Progress

Project Overview

This project documents the setup, configuration, and administration of a virtualized Windows Server environment using Active Directory Domain Services (AD DS).

The goal is to develop practical IT support and system administration skills through hands-on experience with user management, network configuration, access controls, and troubleshooting.

This lab will also provide a foundation for future cybersecurity projects involving identity management, security monitoring, and incident investigation.

Objectives

Install and configure Windows Server in a virtualized environment.

Deploy Active Directory Domain Services and configure a domain controller.

Configure DNS and join a Windows workstation to the domain.

Create and manage user accounts, security groups, and Organizational Units (OUs).

Implement and test Group Policy Objects (GPOs).

Troubleshoot common authentication and connectivity issues.

Explore Windows security logs and account-related security events.

Technologies & Tools

Oracle VirtualBox — Virtualization platform

Windows Server — Server operating system

Windows 11 — Client workstation

Active Directory Domain Services (AD DS) — Centralized identity management

DNS — Domain name resolution

Group Policy — Centralized configuration and security settings

PowerShell — Windows administration and automation
